# Empanatin System 🥟🧑🏻‍💻

## ¿Qué es Empanatin? 😊

Empanatin es mi emprendimiento universitario. Más que un negocio es una comunidad (una comunidad adicta a las empanadas).
Todo empezó como un chiste, hasta que un día llegue a la U con una cajita de emapanada sy ají. A la gente le encantó,
así que aproveché y oficialicé mi emprendimiento como Empanatin (Martin + Empanadas = Empanatin).

## ¿Qué es Empanatin System? 👽
A punto de iniciar un nuevo semestre y reabrir las puertas de Empanatin, decidí crear Empanatin System para ahorrarme
el tiempo que antes dedicaba diaria y manualmente a hacer mis cuentas de ganancias, sacar el capitar para reinvertir
y hacer los cálculos de cuando comprar la materia prima y salsas.
Así que decidí crear Empanatin System para cambiar mi plantilla de Notion que tardaba casi 30 min en llenar por un
sistema que me permita hacer todo en solo 5 minutos.
